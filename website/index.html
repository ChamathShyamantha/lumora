Questions

Is it really free? What's the catch?

There isn't one. Every effect and feature is free, with no account and no subscription, and there's no paid version planned. Ko-fi is there if you want to say thanks.

Which devices does it work with?

Lumora drives hardware through OpenRGB, which supports thousands of keyboards, mice, mousepads, RAM kits, motherboards, GPUs, fans and LED strips. No RGB hardware? Add virtual devices and design effects anyway.

Do I need an AI subscription for the AI designer?

No. Use your own API key with any provider, run a free local model with Ollama or LM Studio, or skip keys with "Use any AI chat": copy the prompt into ChatGPT, Claude, Gemini or Copilot and paste the reply back.

Is my API key safe?

Keys are encrypted with Windows' own protection and stored only on your PC. They're sent to the AI provider you chose and nowhere else.

Can effects from other people harm my PC?

Effects run in a locked-down sandbox with no network and no access to your files or the app, so you can import ones you're sent.

Mac or Linux?

Windows first. Mac and Linux are on the wish list.
